# VayuCare

**Personalized Weather & Air Quality Health Advisory**

VayuCare combines live weather and air quality data with a user's personal health profile to generate plain-English, AI-personalized safety guidance — instead of the same generic pollution alert shown to everyone.

**Live Demo:** https://vayucare-six.vercel.app/


---

## The Problem

Generic weather and AQI alerts apply the same threshold to everyone. An asthma patient, an outdoor worker, and a healthy adult all receive the identical warning today — even though their actual risk from the same air quality can be completely different.

## The Solution

VayuCare asks a few quick questions about the user (age group, health condition, daily activity level), then combines that profile with live environmental data to generate a personalized health advisory using an LLM — along with hardcoded, rule-based safety warnings for genuinely high-risk situations that never depend on AI to fire correctly.

---

## Features

- **Live city search** with geocoding
- **Real-time weather data** (temperature, humidity, forecast) via Open-Meteo, with an automatic fallback provider if the primary source is rate-limited
- **Live AQI data** via WAQI, with concentrations recalculated to the **Indian National AQI (CPCB)** standard rather than the default US EPA scale, since these two standards report meaningfully different numbers for the same air
- **Health profile** — age group, health condition, and occupation/activity level
- **AI-personalized advisory** — generated by Groq's LLM (`llama-3.1-8b-instant`), reasoning over the user's specific profile and current conditions
- **Rule-based fallback advisory** — if the LLM call fails for any reason, a deterministic rules engine still produces a sensible advisory so the app never breaks
- **Safety Note alerts** — a separate, hardcoded (non-AI) warning card that appears automatically for high-AQI conditions combined with a vulnerable profile (children, seniors, asthma, heart conditions, pregnancy)
- **Alert history & trend view** — tracks recent readings per city with deduplication, so repeated searches don't clutter the history
- Source station transparency — shows exactly which monitoring station a reading came from, plus a last-updated timestamp

## How AI Is Used

This project uses AI in one specific, well-scoped place: **generating the personalized advisory text**. The LLM (via Groq) receives the current weather, current AQI, and the user's health profile, and produces a short, plain-English recommendation tailored to that combination.

Everything safety-critical is deliberately **not** left to the LLM:
- The **Safety Note** warnings for high-risk scenarios are static, hardcoded, rule-based text — guaranteed to fire correctly regardless of AI availability
- The **Indian AQI calculation** uses the official CPCB breakpoint formula applied to raw pollutant concentrations, not an AI estimate
- If the Groq API call fails for any reason, a **deterministic rules-based fallback** advisory is shown instead of a broken or blank UI

All weather and AQI data displayed is live and fetched in real time — no mock or hardcoded demo data is presented as live results.

## Getting Started (Local Setup)

### Prerequisites
- Node.js (v18+)
- A free [WAQI API token](https://aqicn.org/api/)
- A free [Groq API key](https://console.groq.com)

### 1. Clone the repository
```bash
git clone https://github.com/dakshpatni08632/Vayucare.git
cd Vayucare
```

### 2. Set up the backend
```bash
cd server
npm install
```

Create a `.env` file in `server/`:
```
WAQI_TOKEN=your_waqi_token_here
GROQ_API_KEY=your_groq_key_here
```

Run the backend:
```bash
npm start
```
Backend runs on `http://localhost:5000` by default.

### 3. Set up the frontend
```bash
cd ../client
npm install
```

Create a `.env` file in `client/`:
```
VITE_API_URL=http://localhost:5000
```

Run the frontend:
```bash
npm run dev
```
Frontend runs on `http://localhost:3000`.
